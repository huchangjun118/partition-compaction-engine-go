# partition-compaction-engine-go

面向事件类数据长期存储的本地分区存储引擎。数据按**时间桶 + 主键哈希桶**二级分区写入，
支持分区裁剪查询、小文件合并、冷热分级存储与保留期自动淘汰。

## 数据模型与分区

- 记录：`{Key, Timestamp(ms), Value}`，追加写，不改写。
- 分区键：`PartitionKey{TimeBucket, KeyBucket}`。
  - `TimeBucket = Timestamp / TimeBucketWindow`
  - `KeyBucket = FNV32(Key) % KeyBuckets`
- 每次 `Write` 按分区把记录排序后落成一个不可变段文件（`data/hot|cold/*.seg`），
  并通过一次清单（`manifest.json`）原子提交发布。

## 一致性语义

1. **快照读**：`Query` 在开始时固定清单版本并为每个段计入读者引用，
   整个查询期间看到的是同一完整版本，不会看到合并/迁移/淘汰的中间状态。
2. **原子替换**：合并、迁移、淘汰都遵循同一协议——
   新段先写临时文件、`fsync`、`rename` 落盘，然后清单通过「临时文件 + rename」原子提交，
   最后旧文件进入废弃队列，**等所有持有引用的读者释放后才物理删除**。
   正在被读取的数据永远不会被删除或替换。
3. **合并不改写数据**：合并输出是输入段记录的全集归并（按 `(Key, Timestamp)` 排序），
   不去重、不丢弃，合并前后任意查询结果逐行一致。
4. **崩溃恢复**：任何时刻进程退出，重启后只会看到某个完整的清单版本。
   启动恢复会清理：未完成的临时文件（`*.tmp`）、未被清单引用的孤儿段文件
   （已落盘但未提交的合并产物）。不会重复累计，也不会丢失已提交数据。
   清单引用的文件缺失视为损坏，`Open` 直接报错。
5. **保留期淘汰**：仅淘汰**整段**超出保留窗口（`MaxTS < now - RetentionWindow`）的段；
   部分过期的段保留至完全过期。淘汰同样走快照安全协议，不影响在途读者。
6. **分层透明**：段的层级（hot/cold）记录在清单中，读取方通过快照定位文件，
   无需感知数据位于哪一层。

## 并发与调度

- 写入、查询与后台任务（合并/迁移/淘汰）完全并发；清单更新由互斥锁串行化，
  段文件不可变，读者通过引用计数保护。
- 后台调度器周期扫描，任务提交到固定大小的 worker 池（`CompactionConcurrency`）。
- **分区级串行、分区间并行**：同一分区同一时刻至多一个合并任务；
  某个慢分区/超大分区的合并不阻塞其他分区的写入、查询与合并。
- `Tasks()` 返回所有后台任务的可观测状态：`pending / running / done / failed`（含错误信息）。
- `CompactNow()` 同步执行一轮调度，用于手动触发与测试。

## 配置项

| 字段 | 默认 | 说明 |
|---|---|---|
| `KeyBuckets` | 4 | 主键哈希桶数（分区数上限维度之一） |
| `TimeBucketWindow` | 1h | 时间桶宽度 |
| `CompactionThreshold` | 4 | 分区内段文件数达到该值触发合并 |
| `CompactionConcurrency` | 2 | 后台 worker 并发度 |
| `RetentionWindow` | 0（关闭） | 保留窗口，整段超出即淘汰 |
| `ColdAfter` | 0（关闭） | 段创建超过该时长迁移到冷层 |
| `ScheduleInterval` | 100ms | 后台调度周期 |

`SetConfig` 运行时生效，**只影响后续调度决策**；已落盘的段与分区布局保持有效，
无需重建（注意：`KeyBuckets`/`TimeBucketWindow` 改变后新旧数据分区口径不同，
建议仅在空库或理解后果时调整）。

## 查询与分区裁剪

`Query{StartTS, EndTS, Keys}`：

1. 分区裁剪：按时间桶范围与主键桶集合排除无关分区；
2. 段级裁剪：按段的 `MinTS/MaxTS/MinKey/MaxKey` 进一步排除；
3. 行级过滤：对命中段逐行精确匹配。

结果与全量扫描逐行一致（`engine_test.go` 中有随机化对照测试保证）。

## 目录布局

```
<dir>/
  manifest.json        # 清单：版本、段元数据（原子提交）
  data/hot/*.seg       # 热层段文件
  data/cold/*.seg      # 冷层段文件
```

```sh
go test -race ./...
```

覆盖：分区裁剪正确性（随机化对照全量扫描）、合并前后结果一致、
并发读写与合并、读者快照保护、崩溃恢复（孤儿/临时文件清理）、
保留期淘汰、分层迁移、配置变更、后台自动调度与分区隔离。
